# Step 1
- PhoneInfo 클래스 생성
  - 속성 : name, phone_number, birth, region
  - birth, region은 입력 안 할수도 있음
  - 기능 : 자기 정보를 출력하는 메소드

- main() 함수 만들어 객체 3가지 생성후 객체 자신의 정보 출력하기

# Step 2
- 메뉴 : 1.데이터 입력 0.프로그램 종료
- 키보드로부터 정보를 입력 받아 객체 만들기

# step 3
- PhoneBookService 클래스 생성 -> CRUD 기능만 분리해서 사용
  - 전화번호를 저장할수 있는 컬랙션 - 리스트
  - 기능 : 입력, 전체출력 (2. 조회, 3.삭제, 4. 수정)
    - 입력된 값은 리스트에 저장 된다
    - 조회는 이름을 기준으로 검색해서 찾은 정보를 출력한다.
    - 삭제는 이름을 기준으로 삭제하고 처리 결과를 메세지로 알려준다
    - 수정할 때는 이름은 수정하지 않고 나머지 정보만 수정한다

# Step 4
- PhoneInfo를 상속받은 PhoneUnivInfo, PhoneCompanyInfo 클래스 생성하기
- PhoneUnivInfo에는 major속성이 추가
- PhoneCompanyInfo에는 company속성 추가
- 필요한 메소드 오버라이딩 하기
- 입력시 일반, 대학, 회사 구분하여 입력받기
- 수정시 일반, 대학, 회사 구분하여 입력받기
- PhoneInfoService의 객체는 오직하나만 생성되는 싱글톤으로 구성
